# Holdem Tournament Builder

Backend для домашних офлайн-турниров по техасскому холдему.

Приложение рассчитывает раскладку фишек, структуру блайндов и рекомендации
призовых. Организатор сохраняет участников, ребаи и фактические выплаты.
Карточку можно открыть и исправить в любой момент. Есть режим банка с
отметками оплат и режим P2P с расчётом переводов.

Go, PostgreSQL, JSONB, chi, pgx. Пока без frontend и аутентификации.

## Запуск

Нужны Go 1.25+, PostgreSQL и golang-migrate. Для новой версии используй
отдельную пустую БД: старый формат карточек не поддерживается.

Задай `DATABASE_URL` для выбранной БД, затем:

```sh
migrate -path migrations -database "$DATABASE_URL" up
go run ./cmd/server
```

API доступен на `http://localhost:8080`, проверка сервера: `GET /health`.

## Проверки

```sh
go test ./... -race
go vet ./...
```

Интеграционные тесты включаются через `TEST_DATABASE_URL`. Они очищают
таблицу `tournaments`: используй только отдельную тестовую БД с именем,
заканчивающимся на `_test`, и заранее применёнными миграциями.
Без переменной эти проверки пропускаются.
